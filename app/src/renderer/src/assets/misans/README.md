# MiSans

界面主字体，使用 MiSans 可变字体（VF）子集，family 名称 `MiSans VF`。

- 上游下载：https://hyperos.mi.com/font/download
- 本仓库文件来源：npm 包 `misans@5.0.0`（github.com/dsrkafuu/misans），Apache License 2.0
- 文件：`MiSansVF.min.css` + 56 个按 unicode-range 拆分的 `woff2`
- 用途：渲染层全局字体，不修改字形
